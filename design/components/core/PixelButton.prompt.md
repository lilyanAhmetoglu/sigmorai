Beveled pixel button for every action — primary (Ember) for the one main CTA per view, xp (Spark) for claiming rewards, success for "Run tests / Submit".
```jsx
<PixelButton variant="primary" size="lg">Start Quest</PixelButton>
<PixelButton variant="secondary" size="sm">Hint (−20 XP)</PixelButton>
```
Variants: primary · xp · success · secondary · danger · ghost. Sizes sm/md/lg. Labels are UPPERCASE verbs.
