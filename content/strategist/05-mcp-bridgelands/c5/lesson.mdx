## Why it matters

A demo of an AI integration costs almost nothing. The bill that matters comes later, when thousands of requests a day each carry the same overhead. Leaders who only ask "what is the price per million tokens?" get surprised. The better question is: what does one finished task cost, and what will it cost next year?

This chapter gives you a method, not a price list. Prices change often, so always read them from the vendor's live page.

## Step 1: count the tokens you didn't think about

Both vendors bill by **tokens**, small pieces of text. Input and output have separate prices. Anthropic's pricing page lists prices "per MTok" (million tokens). OpenAI's pricing page lists "prices per 1M tokens", with separate rates for input, cached input and output.

An integration adds tokens beyond the user's question:

- **Tool definitions.** Anthropic's page says tool requests are priced on all input tokens sent, "including in the `tools` parameter" (tool names, descriptions and schemas). OpenAI's function calling guide says function definitions "count against the model's context limit and are billed as input tokens."
- **Tool calls and results.** Anthropic lists the `tool_use` and `tool_result` content blocks as extra tokens too. A big result, such as a whole document, costs as much as a big question.
- **A hidden tool prompt.** When you use tools, Anthropic's API adds its own system prompt. The page lists the size per model, for example 496 tokens for Claude Haiku 4.5.
- **Tool fees.** Some server-side tools add usage charges. Anthropic's page lists web search at $10 per 1,000 searches, plus tokens. OpenAI's MCP guide says you only pay for tokens when importing tool definitions or making tool calls, with no extra fee per tool call.

OpenAI's guide suggests keeping the tools loaded at the start of a turn to fewer than 20, as a soft suggestion. Anthropic's MCP connector and OpenAI's `allowed_tools` let you switch off tools you don't need. This is the same control you met in the security chapter, now saving money too.

Tokens also differ by model. Anthropic's page says Claude 4.7 and later models use a newer tokenizer that produces "approximately 30% more tokens for the same text." So the same task can cost more tokens after a model change, even at the same price per token.

## Step 2: do the sum for one task

Prices below come from Anthropic's pricing page, **checked on 2026-10-06**. Claude Haiku 4.5 is listed at $1 per MTok for input, $5 per MTok for output and $0.10 per MTok for a cache hit. The workload is our own made-up example.

A support assistant has tools that need 3,000 tokens of definitions. It handles 100,000 requests a month.

- Definitions: 3,000 × 100,000 = 300 million tokens, or $300 a month.
- That is spent before the user has typed a word.

Cut the tool list to what the task needs and this line falls with it.

## Step 3: use the two discounts

**Caching.** Both vendors let you reuse an unchanged start of the prompt at a lower price. Anthropic's pricing page says a cache read costs 0.1x the base input price on most models (less on a few), and a 5-minute cache write costs 1.25x. OpenAI's caching guide says that on GPT-5.6 and later, a cache read costs 0.1x the input price on most of these models and a cache write costs 1.25x. Older OpenAI models use a cached-input price set per model, with no write charge.

In the example, reading the definitions from cache would cost about $30 instead of $300. (We ignore the write cost to keep it simple.)

There is a catch. Anthropic's caching page says changing tool definitions (names, descriptions, parameters) "invalidates the entire cache". OpenAI's guide says changing tool names, descriptions, schemas or order breaks cached prefixes. So frequent edits to your tools cost real money.

**Batch.** Anthropic's pricing page lists a 50% discount on input and output for the Batch API. OpenAI's batch guide also lists a 50% discount compared to synchronous APIs. Anthropic says most batches finish in under an hour. OpenAI says results come within 24 hours. Use batch for work nobody waits on, such as overnight summaries or evaluations. Don't use it for a live chat.

Anthropic's page says these discounts can stack with each other.

## Step 4: add what the price page can't show

The vendor page covers model usage only. The rest of the bill is yours. This checklist is our own framework for this course:

1. **Build once.** Engineer time to connect, test and secure the integration.
2. **Run.** Model usage per task, from steps 1 to 3, times the volume you expect.
3. **Maintain.** Time to update tools, prompts and tests. Vendors retire models, and each retirement is a small project. The next chapter covers this.
4. **Review and support.** People who check outputs and handle errors.

**Build or buy?** Buying a ready-made integration moves lines 1 and 3 to a supplier, but adds a licence fee and a dependency on that supplier. Building costs more at the start and gives you control. Neither is always cheaper. Compare the four lines for both options over two or three years.

## Key points

- Tool definitions, tool calls and results all count as input tokens, on every request.
- Price one finished task, not one million tokens.
- Caching and batch can each cut cost, but stable tool lists and non-urgent work are the conditions.
- Switching models can change the token count for the same text.
- Add build, run, maintain and review costs, and compare build and buy over several years.
