## Why it matters

You don't need a developer to try an agent any more. OpenAI, Anthropic and Google now let you describe one in plain words, or set it up on a screen with switches and boxes. That makes agents fast to start. It also means a business team can connect an agent to company data before anyone has checked what it may reach.

This chapter shows what the no-code options do, and what still needs a careful owner.

## Describe it in plain words

OpenAI's cookbook shows ChatGPT **workspace agents**. You build one through a conversational builder: you describe the workflow, and the builder drafts the agent's name, instructions and connected apps. The cookbook says they are in research preview for ChatGPT Business, Enterprise and Edu customers.

Its example agent prepares sales meeting briefs. It runs on a schedule (each day at 4pm), reads calendars, searches SharePoint and the web, writes a brief and sends a summary. The agent can also use **skills** (packaged instructions and files for a repeated task) and **memory** (a folder where it keeps notes between runs). The cookbook notes that this memory is not shared between different users of the agent.

## Set it up on a screen

Other tools give you a visual screen instead of a chat:

- **Anthropic's Console** lets you create and test Claude Managed Agents visually: pick a model, write the system prompt, add tools, MCP servers (connections to outside tools) and skills. You can run a test session on the page. Console shows the matching API request, and you then run the agent from your code. So the setup needs no code, but going live does. Managed Agents is in beta.
- **Google AI Studio** has an agents playground to prototype managed agents without writing API calls. You start from templates and switch built-in tools on or off, such as Google Search or file tools.
- **Claude Code Desktop** can run scheduled tasks, for example a morning briefing from your calendar and inbox. You write the instructions like a normal message and pick a schedule.

## Know the small print

No-code tools still have rules you must read. Three examples from the docs:

- **Where it runs.** Claude Code Desktop's local tasks run only while the app is open and the computer is awake. After a missed run, Desktop starts one catch-up run, so the docs warn a 9am task might run at 11pm.
- **What it costs.** Google warns that one prompt to its playground agent can lead to unbounded token use, because the agent plans, runs code and repeats. It advises clear stop criteria in the prompt and a narrow task. Templates also call the Gemini API with your key, which can add charges.
- **Who switches it on.** OpenAI's cookbook lists admin steps first: agents enabled for the workspace, permission to build and share, and the needed apps enabled.

## Products change fast

OpenAI's **Agent Builder** is a visual canvas where you connect steps (nodes) into a workflow. OpenAI is deprecating it, and its docs say it is scheduled to shut down on November 30, 2026.

OpenAI's migration guide offers two paths: export the workflow as Agents SDK code, or rebuild it as a ChatGPT workspace agent. It warns that the export does not convert your workflow graph or guarantee that every behaviour transfers unchanged. Workflows that rely on fixed, predictable steps may not move well to a workspace agent.

Example: a team built a fixed invoice-checking flow on a visual canvas. When the canvas closes, it must rebuild and retest. The team that kept its test cases and expected results can compare old and new in a day. The team that didn't must start from memory.

## Test before you share

The cookbook gives a simple test: ask the agent to prepare a brief for a meeting you already had last week, and compare it with the brief a person wrote. It also notes that a new agent is, by default, available only to its maker. Keep it that way until the tests pass.

This checklist is a tool for this course:

1. **Name an owner** who updates the instructions and checks the results.
2. **Test on past cases** with known good answers.
3. **Check the connections** and what each one can do (next chapter).
4. **Write the stop rule and budget** into the instructions.
5. **Keep an exit plan:** your instructions, tests and examples, outside the tool.

## Key points

- No-code agents are built by describing them or by setting switches on a screen.
- Some tools are no-code to set up but need code to go live (Anthropic's Console).
- Read the small print: where it runs, what it costs, who must switch it on.
- Products change: OpenAI's Agent Builder shuts down on November 30, 2026.
- Test on past cases, share late, and keep your tests outside the tool.
