Prompt Forest taught you to write a good brief. This realm is about the tools your team writes those briefs in: the AI products people use at their desks every day.

A note on dates: product names, plan names and features below are from each vendor's help pages in October 2026. These products change often, so check the page before you buy.

## Four kinds of tool

The big AI apps now offer several ways to work. We sort them into four kinds (our grouping, not a vendor term):

| Kind          | Use it when                                     | Examples                                            |
| ------------- | ----------------------------------------------- | --------------------------------------------------- |
| Chat          | One question, or a short back-and-forth         | Claude chat, ChatGPT Chat, the Gemini web app       |
| Project space | Many chats need the same files and instructions | Claude projects, ChatGPT projects, Gemini notebooks |
| Desk agent    | You hand over a whole task and want a file back | Claude Cowork, ChatGPT Work                         |
| API           | A developer builds AI into your own system      | Claude API, OpenAI API                              |

A **desk agent** is an AI app that plans and does a multi-step task for you, then hands back a finished result (our plain gloss). An **API** is a way for software to call the model directly, without the chat app (our plain gloss).

## Chat: one question at a time

Chat is the simplest tool. OpenAI's guide says: "Use Chat for a question or back-and-forth." Its table lists examples: "Ask a question, search the web, brainstorm, draft a message, compare options".

Google's help page for the Gemini app lists similar jobs, such as a summary of a complex topic or "first drafts of outlines, emails, blog posts". It also warns: "Gemini Apps can make mistakes. When using Gemini Apps, double-check responses".

Our example: "Rewrite this email to a client so it is shorter and kinder." One chat, one answer, done.

## Project space: the same context, many chats

When the same files and instructions come back again and again, a project saves you from pasting them each time.

- **OpenAI:** "Create a project when work will continue over time, produce more than one output, or depend on the same files and sources. Start a chat without a project when the work is self-contained and doesn't need shared project context."
- **Anthropic:** "Projects allow you to create self-contained workspaces with their own chat histories and knowledge bases. Within each project, you can upload documents, provide context, and have focused chats with Claude."
- **Google:** in the Gemini app, notebooks "provide a continuous chat experience that remembers your sources, instructions, and ongoing discussions."

Our example: a team writes a weekly client report with the same template, brand guide and client notes. One project holds them; each week starts a new chat inside it.

## Desk agent: hand over the whole task

Some work has many steps: read files, compare them, build a spreadsheet or a deck. Here you describe the result you want, not each step.

- **OpenAI:** "Turn on Work in the switcher when you want ChatGPT to carry a larger task through to a reviewable result." Its table: ChatGPT Work is for when you "Define an outcome and get a reviewable result", for example "Create a deck, analyze files, draft a report, build a project plan".
- **Anthropic:** "Describe the outcome you want, and Claude works through the steps on its own: searching the web, reading your files, running code, and putting the results together."

The line between chat and desk agent is moving. Anthropic says its new experience merges Claude Cowork and chat "into a single conversation, so you don't need to decide which option better suits your task before getting started". It is "rolling out gradually, starting with Pro and Max plans". So name the job first, then find the button in your product (our advice).

Two costs come with this kind of tool:

1. **It uses more of your plan.** Anthropic: "Longer agentic tasks that search the web, run code, or create files generally use more than a quick question." OpenAI: "ChatGPT Work usage inside ChatGPT uses the same pricing, credits, and usage limits as Codex."
2. **You must check the result.** OpenAI: "Review consequential actions before approving them, and check the final result before you use or share it." Anthropic: "For work with real consequences, like sending messages or changing important files, stay close and review what Claude does."

Our example: "Read these 30 survey exports and build one spreadsheet with a tab per region." That is a desk agent task.

## API: when a developer builds it in

The chat apps are for people. The API is for software. Anthropic's help page puts it this way: Claude's paid plans "give subscribers access to Claude on the web, desktop, and mobile", while "The Claude Console is our developer platform providing API keys and access to Claude models for building applications and integrations."

The money is separate too:

- **Anthropic:** "the Claude API is billed separately" from a paid Claude plan.
- **OpenAI:** "API token prices are separate from subscription usage; don't use them to estimate included tasks."

Our example: "Tag every new support ticket in our help desk system, day and night, with no one pressing a button." A person does not open a chat for each ticket. A developer connects the help desk to the model through the API, and that use has its own bill.

OpenAI also offers **Codex** in the same app. Its table says Codex is for when you "Use developer tools and see technical details", such as "Debug code, run tests, review a PR". For most office work, Chat or Work is the fit.

## Pick the tool per task

A short test for each task (our advice):

1. **Is it one question?** Use chat.
2. **Will it repeat with the same files and instructions?** Use a project space.
3. **Does it have many steps and end in a file?** Use a desk agent, and plan time to review the result.
4. **Must it run inside another system, with no person starting it?** That is an API job for a developer, on a separate budget.

Start with the smallest tool that does the job (our advice). A desk agent for a one-line question wastes usage. A chat for a 30-file task means a lot of copying and pasting.

Not every tool is open to every person. OpenAI: "Features depend on your plan, platform, region, rollout, and workspace settings. Your workspace administrator can control access to ChatGPT Work, plugins, browser use, and network access." Check what your workspace allows before you plan around a feature (our advice).

## Key points

- Four kinds of tool: chat, project space, desk agent and API (our grouping).
- Chat: one question or a short back-and-forth.
- Project space: many chats that need the same files and instructions.
- Desk agent: a multi-step task with a finished file at the end. It uses more of your plan, and you must review the result.
- API: a developer builds AI into your own system. Anthropic and OpenAI bill it apart from the chat plans.
- Name the job first, then pick the smallest tool that does it.
