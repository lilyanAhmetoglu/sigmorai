## Goal

After this lesson you can:

- Name the four kinds of AI workspace tool: chat, project space, desk agent and API.
- Pick the smallest tool that does a piece of work, and say what checking the result needs.
- Explain which costs a chat seat covers, and which costs come on a separate bill.

## The problem

An architecture firm with 14 staff bought paid seats on an AI chat product two months ago. A **seat** is one paid login for one person. Now two complaints reach the office manager.

First, several people hit their usage limit by Wednesday. The usage page shows why. They start every request as a long agent task, even "fix the grammar in this sentence". Their reason: "the agent mode is the strongest one, so it must be the best".

Second, the three people who write tenders (bids for new building jobs) each keep a private copy of the fee table and the list of past projects. Last month two tenders went out with different fees.

The office manager wants a one-page team guide: which tool for which kind of work. The product facts below come from each vendor's help pages (October 2026).

## The idea

AI products offer several ways to work. We sort them into four kinds. The names are ours.

```text
chat           one question, or a short back-and-forth
project space  many chats that reuse the same files and instructions
desk agent     a whole task with many steps, handed back as a file
API            software calls the model, with no person in a chat
```

Our comparison: chat is a quick question to a colleague. A project is a shared shelf of files. A desk agent is a whole job you hand over and check later.

**Chat.** The [ChatGPT docs](https://learn.chatgpt.com/docs/use-chatgpt) say: "Use Chat for a question or back-and-forth." Their examples: "Ask a question, search the web, brainstorm, draft a message, compare options". The [Gemini docs](https://support.google.com/gemini/answer/13275745) list similar jobs, such as "first drafts of outlines, emails, blog posts".

**Project space.** A **project** is a saved space where many chats share the same files and instructions. The [ChatGPT docs on projects](https://learn.chatgpt.com/docs/projects) give a clear rule:

- "Create a project when work will continue over time, produce more than one output, or depend on the same files and sources."
- "Start a chat without a project when the work is self-contained and doesn't need shared project context."

The same page adds a limit: "A ChatGPT project doesn't provide direct access to a folder on your computer, so upload or connect the sources you want ChatGPT to use." The [Claude docs on projects](https://support.claude.com/en/articles/9517075-what-are-projects) say: "Projects allow you to create self-contained workspaces with their own chat histories and knowledge bases." In the Gemini app, notebooks do this job. The [Gemini docs](https://support.google.com/gemini/answer/16972047) say notebooks "provide a continuous chat experience that remembers your sources, instructions, and ongoing discussions."

**Desk agent.** A **desk agent** is our name for an AI mode that plans and does a task with many steps, then hands back a finished result. Claude Cowork and ChatGPT Work both do this.

- The ChatGPT docs say to turn on Work "when you want ChatGPT to carry a larger task through to a reviewable result".
- Their examples: "Create a deck, analyze files, draft a report, build a project plan".
- The [Claude docs](https://support.claude.com/en/articles/16761823-claude-cowork-and-chat-are-one-claude) describe it like this: "Describe the outcome you want, and Claude works through the steps on its own: searching the web, reading your files, running code, and putting the results together."

A desk agent has two costs:

1. **It uses more of your plan.** The Claude docs: "Longer agentic tasks that search the web, run code, or create files generally use more than a quick question." (**Agentic** means done by an agent, step by step.)
2. **You must check the result.** The ChatGPT docs: "Review consequential actions before approving them, and check the final result before you use or share it." The Claude docs: "For work with real consequences, like sending messages or changing important files, stay close and review what Claude does."

The line is moving. In a new Claude experience, chat and Cowork are "merged into a single conversation", and it is "rolling out gradually, starting with Pro and Max plans". So name the job first, then find the button in your product.

**API.** An **API** (application programming interface) is a way for software to call the model directly, without the chat app. A developer builds it into another system. The [Claude docs on billing](https://support.claude.com/en/articles/9876003-i-have-a-paid-claude-subscription-pro-max-team-or-enterprise-plans-why-is-claude-api-usage-billed-separately-from-my-paid-claude-plan) draw the line:

- Paid plans "give subscribers access to Claude on the web, desktop, and mobile".
- "The Claude Console is our developer platform providing API keys and access to Claude models for building applications and integrations." (An **API key** is a password for software.)

**A seat does not pay for the API.**

- The same Claude page says "the Claude API is billed separately" from a paid plan.
- It adds: "Claude Max and Team plans include monthly credits for the Claude API." A **credit** here is a set amount of API use each month. Nothing on the page says it is unlimited.
- The [ChatGPT pricing page](https://learn.chatgpt.com/docs/pricing) says: "API token prices are separate from subscription usage; don't use them to estimate included tasks." (A **token** is a small piece of text. APIs charge per token.)

**Not every tool is open to every person.** The ChatGPT docs: "Features depend on your plan, platform, region, rollout, and workspace settings." And: "Your workspace administrator can control access to ChatGPT Work, plugins, browser use, and network access."

## Worked example

### Step 1: the weak guide

```text
AI guide (draft)
- Use agent mode for everything. It is the strongest.
- Keep your own copy of the files you need.
```

What goes wrong:

- Agent mode for "fix this sentence" burns the plan. That is why limits run out by Wednesday.
- Three private copies of the fee table drift apart. One shared project holds one copy.

### Step 2: the test

Our advice: ask three questions about each kind of work.

1. **Is it one question, or a short back-and-forth?** Use chat.
2. **Will it repeat with the same files and instructions?** Use a project space.
3. **Is it a long job with several steps and a finished document at the end?** Use a desk agent, and plan time to review.

### Step 3: the good guide

```text
AI guide: which tool for which work
Chat         Quick rewrites, short questions, first drafts
             of an email. Do not use agent mode for these.
Project      "Tenders": company profile, fee table and past
             projects live here, one copy for all three
             writers. Start each new tender as a new chat
             inside it.
Desk agent   "Turn the notes from this site visit into a
             6-slide deck for the client." Read every slide
             before it is sent.
Admin note   Check that your plan and workspace settings allow
             a feature before you plan around it.
```

### Step 4: the hard case

**The hard case is the tender itself.** It repeats with the same files, so it fits a project. But each tender also has many steps (read the brief, fill the fee table, write the method section) and ends in a document. So it also fits a desk agent.

So use both. The ChatGPT docs say: "The same project can contain chats started with Chat or ChatGPT Work." The Claude docs say that in the new Claude experience, "Projects work in every conversation." So the team runs the agent task inside the "Tenders" project. The agent uses the one shared fee table. The team still reviews the finished tender, because it goes to a client.

### Step 5: why it is better

- **Usage goes where it is needed.** Quick questions stay in chat, so long tasks have room.
- **One fee table.** All three writers and the agent use the same file.

## Common mistakes

1. **Using the biggest mode for every request.** Long agent tasks use more of the plan than quick questions. Fix: start with chat, and move up only when the job needs it.
2. **Planning around a feature you have not checked.** Your **admin** (the person who manages the team's account), plan or region may turn it off. Fix: check what your workspace allows before you write it into a guide.

## Try it

Not graded. Write your answer down before you read the answer.

Three colleagues at a small law office make these claims. Say if each one is right or wrong, and why.

```text
1. "I made a ChatGPT project and pointed it at the
   Contracts folder on my laptop. Now it can read
   every contract in there."
2. "ChatGPT Work is missing from my menu. The product
   must be broken."
3. "A Gemini notebook keeps track of the sources I
   added, so I don't need to paste them into each
   chat."
```

### Answer

1. **Wrong.** The ChatGPT docs say a project "doesn't provide direct access to a folder on your computer". Upload or connect the contracts the project needs.
2. **Probably wrong.** It may be a setting, not a fault. The ChatGPT docs say features depend on "your plan, platform, region, rollout, and workspace settings", and that an administrator can control access to ChatGPT Work. Ask the admin first.
3. **Right.** The Gemini docs say notebooks remember "your sources, instructions, and ongoing discussions".

## Recap

- Four kinds of tool: chat for quick questions, a project for repeated work with the same files, a desk agent for long jobs that return a document, and the API for software.
- Pick the smallest tool that does the job. Desk agents use more of your plan, and their results need a review.
- A chat seat does not pay for the API. Anthropic and OpenAI bill it apart, and some Claude plans add only a monthly API credit.
