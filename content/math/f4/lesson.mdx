Inside a neural network, one small step repeats again and again: take a list of numbers, mix it with a grid of learned numbers, and pass the result on. That grid is a matrix. This floor covers matrix times vector, matrix times matrix, the transpose, and the layer formula `y = Wx + b`. You only need the dot product from floor 1.

## A matrix is a grid of numbers

A matrix is a table of numbers with rows and columns. Its shape is written rows × columns.

This matrix `W` has 2 rows and 3 columns, so its shape is 2 × 3:

```
W = | 1  0  2 |
    | -1 3  1 |
```

A vector is a matrix with only one row or only one column. Floor 1's vectors fit inside this picture.

## Matrix times vector

To multiply a matrix by a vector, take the dot product of each row with the vector. Each row gives one number.

Example with `W` above and `x = (2, 1, 3)`:

- row 1: `(1, 0, 2)·(2, 1, 3) = 2 + 0 + 6 = 8`
- row 2: `(−1, 3, 1)·(2, 1, 3) = −2 + 3 + 3 = 4`
- result: `Wx = (8, 4)`

The shapes must fit. Each row of `W` has 3 numbers, so `x` must have 3 numbers too. A 2 × 3 matrix takes in 3 numbers and gives out 2. The matrix changes the size of the vector.

## Many dot products at once

Floor 1 scored documents one at a time. A matrix does them all in one step. Put one document vector in each row, then multiply by the query.

Same query `q = (3, 4)` and documents as floor 1:

```
D = | 4  3 |   ← A
    | -4 3 |   ← B
    | 6  8 |   ← C
```

`Dq = (4×3 + 3×4, −4×3 + 3×4, 6×3 + 8×4) = (24, 0, 50)`

Those are the three dot products from floor 1, in one result. The Claude docs' search example does exactly this with NumPy: `similarities = np.dot(doc_embds, query_embd)`. `doc_embds` holds one embedding per document, and the result is one score per document.

## Matrix times matrix

To multiply two matrices, take the dot product of each row of the first with each column of the second. The number at row i, column j of the result is row i of the first matrix · column j of the second.

```
| 1 2 |   | 5 6 |   | 1×5 + 2×7   1×6 + 2×8 |   | 19 22 |
| 3 4 | × | 7 8 | = | 3×5 + 4×7   3×6 + 4×8 | = | 43 50 |
```

The order matters. Swap the two and you get a different answer: the top-left number becomes `5×1 + 6×3 = 23`, not 19.

Shape rule: an (m × n) matrix times an (n × p) matrix gives an (m × p) matrix. The two inner numbers must match.

## The transpose

The transpose of a matrix flips it: rows become columns. It is written with a small T, like `Kᵀ`.

```
| 1 2 3 |ᵀ   | 1 4 |
| 4 5 6 |  = | 2 5 |
             | 3 6 |
```

A 2 × 3 matrix becomes 3 × 2. Floor 8 uses the transpose to compare every token with every other token.

## A layer: y = Wx + b

The basic layer of a neural network, written as math, is a matrix multiply plus one more vector:

`y = Wx + b`: the output y is the weight matrix W times the input x, plus the bias b.

The bias `b` is a vector added at the end, one number per output. Continue the example: `Wx = (8, 4)` and `b = (1, −2)`, so `y = (8 + 1, 4 − 2) = (9, 2)`.

The numbers inside `W` and `b` are the layer's parameters. Training changes them (floor 6 shows how). This small layer has `2 × 3 = 6` weights plus 2 bias numbers: 8 parameters. The Claude glossary describes LLMs as "AI language models with many parameters".

## A learned matrix on top of embeddings

The OpenAI cookbook has a full example of a learned matrix. Its goal: "customize OpenAI embeddings to a particular task". It learns from pairs of texts marked similar or not similar, and "The output is a matrix that you can use to multiply your embeddings."

In its code, the matrix has `embedding_length` rows and `modified_embedding_length` columns (2048 by default). Each embedding is multiplied by it with Python's `@` operator: `modified_embedding_1 = e1 @ matrix`. Here the embedding is a row, so it goes on the left. By the shape rule, a row of `embedding_length` numbers times that matrix gives a row of 2048 numbers.

## Key points

- A matrix is a grid of numbers. Its shape is rows × columns.
- Matrix times vector: one dot product per row. `W` (2 × 3) times `(2, 1, 3)` gives `(8, 4)`.
- One matrix multiply scores many documents at once.
- Matrix times matrix: row · column for every pair. The inner sizes must match, and the order matters.
- A layer is `y = Wx + b`. The numbers in `W` and `b` are the parameters that training changes.
