## Why it matters

"AI" is not one tool. Some models make pictures. Some make video. Some make a voice. Some only look at your pictures and write about them. If you pick the wrong kind, the job fails before you write a single prompt. This lesson gives you a simple map.

## Input and output

Every model has **inputs** (what it can read) and **outputs** (what it can make). The kinds of media are called **modalities**: text, image, video, audio.

Read the output side first. It tells you what the model can make for you.

Example: Anthropic's model overview says all current Claude models support text and image input and text output. So Claude can look at your poster and tell you the logo is too small. But the Claude vision docs say it plainly: Claude "cannot generate, produce, edit, manipulate, or create images." It reads images. It does not make them.

## Four kinds of media model

**1. Image models.** You write a prompt, the model makes an image.

- OpenAI's image API has two parts: _Generations_ (make an image from a text prompt) and _Edits_ (change an existing image, in part or entirely).
- Google calls Gemini's image generation "Nano Banana". Its docs list text-to-image, editing with text and an image, and mixing up to 14 reference images into one result.

**2. Video models.** You write a prompt, or give a first frame, and the model makes a short clip.

- Google's Veo 3.1 makes 8-second videos (720p, 1080p or 4k) with natively generated audio. It can start from reference images or from a first and last frame.

**3. Speech models (text to speech).** You give a script, the model makes a voice track.

- OpenAI's speech endpoint can "narrate a written blog post" and speak in many languages.
- Gemini's speech models take text-only input and give audio-only output. One request can have up to 2 speakers.

**4. Vision models (image in, text out).** You give an image, the model describes or checks it. Claude is one example. Chapter 3 compares vendors.

## Text inside images

Designers often need words in the picture: a headline, a price, a menu. The vendors differ here, so read their notes.

- OpenAI's limits section says the model "can still struggle with precise text placement and clarity".
- Google's docs say Nano Banana can make "legible, stylized text for infographics, menus, diagrams, and marketing assets". It also gives a tip: generate the text first, then ask for an image with that text.

Example: a café wants a menu board image with ten prices. Plan to check every price by eye. If one is wrong, you fix it or set the text in your design tool.

## One campaign, four models

A sneaker brand launches a new shoe. Here is how the jobs map to model types:

| Job                                      | Output you need | Model type                  |
| ---------------------------------------- | --------------- | --------------------------- |
| Hero image for the web page              | image           | image model                 |
| 8-second vertical teaser with sound      | video + audio   | video model                 |
| Voice-over for the teaser, two languages | audio           | speech model                |
| Check 40 shop photos for the logo        | text (a report) | vision model (image → text) |

No single model in this lesson does all four jobs. A media project is usually a small chain of models, with you in the middle.

## What this means for your work

- **Start from the output.** "I need a 9:16 video with sound" points to a video model. "I need feedback on my layout" points to a vision model.
- **Edit is not the same as generate.** If the client likes 90% of an image, an edit tool can change the part that is wrong. You don't have to start again.
- **Check the vendor's own list.** What a model can read and make is in its docs. A model that reads images may not make them.
