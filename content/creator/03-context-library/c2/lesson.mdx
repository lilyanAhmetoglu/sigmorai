## Why it matters

In Prompt Forest, chapter 2, you used reference images in one request. You learned the three jobs: object, character and style. A studio does not have three images. It has hundreds, from many shoots and many years.

So a new question comes up. Which images go into a request? This lesson gives you two words, both ours:

- **Library:** every reference image you own for a brand.
- **Set:** the few images you pick from the library for one job.

You choose the set. The model never sees the rest.

## Start with the job

Before you pick images, name the job each one will do: object, character or style. One image should do one job. Runway's guide says the same in its own words: use "one subject per reference" and avoid references with multiple competing subjects.

Example: a photo of a mug on a busy kitchen counter is a poor object reference. The counter, the plant and the cloth compete with the mug.

## Small and cohesive

What size should a set be? Runway's guide gives two rules for style references in its own Recipes. No other vendor we cite says this, so using them with other tools is our method:

- "Choose references that share a consistent palette, lighting, and mood."
- "Provide a few complementary images rather than one — a small, cohesive set defines the style more reliably."

And it warns: "Don't mix conflicting aesthetics in a single request; generate separately and curate."

Google's table points the same way on size: Nano Banana Pro takes up to 3 style references.

Example: three warm photos with the same terracotta palette make a good style set. A warm photo, a neon night shot and a watercolour painting do not. They pull in three directions.

## The limit is a ceiling

Models accept a number of references, but that number is not a target. Google's guide says its Nano Banana models take up to 14 reference images. Its limits note also says gemini-2.5-flash-image works best with up to 3 images as input. And it says Nano Banana 2 Lite is "not optimized for multiple reference inputs". Realm 1 covered the full table.

OpenAI's image edits guide says you can use "one or more images as a reference". Its example uses four. It gives no ideal number, so test your own set.

More references are more to read and more to pay for. Pick the fewest that do the job.

## Same where it matters, different elsewhere

Here is a trap. You pick three photos of the mug. All three sit on the same wooden shelf. The model may decide that the shelf is part of the mug. Every result then shows a wooden shelf.

Anthropic's prompting guide gives advice for examples in a text prompt: make them "diverse" so the model does not "pick up unintended patterns". That advice is for text, but the idea carries over. This rule is ours:

- Keep **the same** what you want carried over: the glaze colour, the shape, the logo.
- Make **different** what you do not want carried over: the surface, the background, the props.

If a result keeps repeating something you did not ask for, look at what your references have in common.

## Make a card for each reference

A file name tells you little. A **reference card** is a short note kept with the image. It is our method. Put it in the library.

| Field   | Example                                                |
| ------- | ------------------------------------------------------ |
| File    | mug-front-clean-v2.jpg                                 |
| Job     | Object                                                 |
| Copy    | Glaze colour, handle shape, logo position              |
| Ignore  | The white table                                        |
| Status  | Approved, or retired (and what replaced it)            |
| Quality | Largest side in pixels, clean background, no watermark |

The "Ignore" line is useful. It also goes into the prompt, as you learned in Prompt Forest: say what each reference is for.

## Pick a clean source

Runway's reference guide is written for its own Recipes. Using its checklist with any tool is our choice:

- "use the highest-quality source you have." Low-resolution or heavily compressed images "degrade the output".
- The subject should be "clearly the focus, free of clutter and distractions".
- "even, neutral lighting reproduces most faithfully." Harsh shadows and colour casts can "carry into the result".
- For products: keep the product centred and unobstructed. Avoid "heavy reflections, watermarks, or overlaid text".

A stock photo with a watermark across the middle fails the last rule. This also links to rights, the topic of chapter 6.

## Keep the library current

References age. A packshot is replaced after a redesign. A logo changes. Handle each change like a version. These habits are ours:

- **Mark the old one retired.** Say what replaced it. Do not leave both in the same set.
- **Change the set on purpose.** A new set is a new version. Run the same three test briefs on the old and the new set and compare the results side by side.
- **Keep retired files in an archive.** You may need them for an old job.

## What this means for your work

- **Library and set.** Keep the library large. Send a small set.
- **One job per image.** Object, character or style. One subject each.
- **Cohesive, not identical.** Same palette, light and mood for style. Different surface and props for objects.
- **A card for every file.** Job, copy, ignore, status and quality.
- **Retire, don't pile up.** Old versions leave the sets.
