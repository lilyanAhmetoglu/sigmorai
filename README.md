# Sigmorai

A 2D pixel-art RPG for learning AI engineering and agentic systems. [sigmorai.com](https://sigmorai.com)

## Quickstart

```bash
bun install
cp .env.example .env.local   # fill in the values
bun dev
```

Open http://localhost:3000.

## Docs

- `ENGINEERING.md`: stack, architecture, build order
- `DESIGN.md` + `design/`: look and voice
- `AGENTS.md`: layout, commands, rules for humans and agents
